# 工作簿规范

## 推荐工作表

根据数据实际内容保留所需工作表；不需要的转化类型无需创建空表。

1. `店铺_素材汇总`：按笔记 ID 汇总。适用于店铺成交/GMV数据；包含笔记截图、视频拆解、数据分析、投放分析和素材/计划信息。
2. `提交量_素材汇总`：按笔记 ID 汇总。仅在有表单、私信或线索数据时创建。
3. `原始数据`：清洗前或可追溯的原始导出，保留导出字段与日期。
4. `店铺_创意ID汇总`：按创意 ID 汇总。用于比较同笔记在不同定向、单元或计划中的差异。

## 字段与汇总

- 文本 ID 保持文本格式，避免科学计数法或截断。
- 可加总指标：消费、展现、点击、互动、播放、订单、GMV、表单等，按同一筛选条件求和。
- 比率指标不相加：CTR = 点击 ÷ 展现；CPC = 消费 ÷ 点击；进店率 = 进店 ÷ 点击；ROI = 对应 GMV ÷ 消费。分母为 0 时显示 0 或用户指定的不可用标识。
- 合计行必须由合计分子/分母重新计算比率，而不是平均各行比率。
- 表头到合计行的明细行采用统一字体、对齐、边框和行高。合计行单独使用汇总填充色。

## 数据范围

- 仅处理用户确认的日期范围内的原始记录，范围含起止日。
- 先在日期字段过滤，再计算所有汇总、排名、漏斗和合计；不得用全量数据计算后只隐藏范围外明细。
- `原始数据` 工作表也只保留该范围内的行，并在标题或来源说明中标出所用日期范围。
- 文件名使用 `【{供应商}】-笔记&创意-数据{MMDD}-{MMDD}.xlsx`，其中供应商和日期范围必须来自本次用户确认的信息。

## 分析框架

### 视频拆解

每条笔记按以下结构写入：

```text
【标题】
【封面】
【内容概述】
【钩子】
```

只要笔记链接可用，就必须先使用当前可用的浏览/链接访问能力打开链接，核对页面中可见的标题、封面、正文、视频画面或视频描述。将同一笔记 ID 的链接只核对一次，并让拆解内容与该笔记对应。

- 链接可打开时，即使用户未上传视频、截图或正文，也应基于页面可见内容完成拆解。
- 只描述实际看到的页面内容；不要把推测写成画面或剧情。
- 链接不可访问、要求登录、页面正文未加载或视频无法播放时，仍保留四个字段，并将无法核对的字段标为 `待补（链接核对失败：具体原因）`。不要写笼统的“未提供正文/截图”，也不要假装已观看视频。
- 若当前环境没有可用的链接访问能力，标注 `待补（链接核对未执行：当前环境无可用访问工具）`，并在交付说明中说明限制。

### 数据分析

结合本表内排名和完整漏斗，至少说明：相对位置、展示到点击、点击到进店、进店到成交/表单的断点，以及样本量限制。

### 投放分析

```text
【结论】能卖 / 不能卖 / 暂不能判定为能卖
【为什么能卖】或【为什么不能卖】内容与购买意图之间的具体关系
【和数据对应】列出支撑判断的漏斗与 ROI 证据
【动作】明确预算、素材、定向、商品承接或验证动作
```

“能卖”需要有成交效率或稳定线索支撑。“不能卖”常见于高点击/高播放但无成交、ROI 低、进店效率低或内容只停留在围观。进店或成交样本过少时，不下稳定结论。

## 格式与删除规则

- 笔记截图栏留白，不嵌入未授权的图片。
- 每张工作表都开启工作表网格线；不能将 `showGridLines` 设为关闭。
- 所有分析表和原始数据表的已用表格区域，必须从表头行一直到合计行/最后一条数据行对每个单元格应用统一的细实线边框（含内部横线、内部竖线和外框）。不要只依赖应用程序默认网格线。
- 输出前在 Excel 或 WPS 的正常缩放比例渲染检查：边框必须连续可见，明细行不得出现无边框、不同边框或空白残留行。
- ROI 明细单元格使用条件格式：绿色为高效、黄色为观察、红色为低效。默认阈值仅在未提供业务目标时使用。
- 删除任一字段时，检查并清除该字段所在列的标题、单元格值、公式、共享公式、条件格式、格式残留和引用；不要只隐藏列。
- 删除后的最后一列右侧不得保留可见公式结果或数值。
